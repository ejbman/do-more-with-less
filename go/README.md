## The idea in 15 seconds

You pay for AI subscriptions. Then you pay OpenRouter per token for the same work.
This router flips the order: **your plans get exhausted first**, metered APIs are the
last resort, and everything is one transparent JSON file on your own hardware.

See [py/router.py](py/router.py) — the whole router in one auditable file.
